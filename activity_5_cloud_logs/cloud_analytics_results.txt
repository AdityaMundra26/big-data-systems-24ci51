--- [ATHENA QUERY 3: Endpoint Reliability & Latency Degradation] ---
SELECT uri_path, http_method, COUNT(*) AS total_calls,
       SUM(CASE WHEN status_code >= 500 THEN 1 ELSE 0 END) AS server_errors_5xx,
       SUM(CASE WHEN status_code BETWEEN 400 AND 499 THEN 1 ELSE 0 END) AS client_errors_4xx,
       ROUND(AVG(latency_ms), 1) AS avg_latency_ms,
       ROUND(APPROX_PERCENTILE(latency_ms, 0.95), 1) AS p95_latency_ms
FROM s3_web_server_logs
GROUP BY uri_path, http_method
ORDER BY server_errors_5xx DESC, total_calls DESC;

ESTIMATED CLOUD INFRASTRUCTURE RESOURCE & COST MODEL
=====================================================================================
Workload Assumptions: 100 GB daily compressed server logs (3 TB / month), 500 Athena analytical queries / month
-------------------------------------------------------------------------------------
1. Storage (Amazon S3 Standard Tier):
   - Raw Storage: 3,000 GB * $0.023 / GB = $69.00 / month
   - After Parquet Columnar Compression (75% reduction): 750 GB * $0.023 = $17.25 / month
   - S3 Lifecycle Rule to Glacier Flexible Retrieval after 90 days: $0.0036 / GB

2. Metadata Cataloging (AWS Glue Data Catalog):
   - Glue Crawler runs 1x daily (0.5 DPU-hours/day = 15 DPU-hours/mo) * $0.44/DPU-hour = $6.60 / month
   - Glue Data Catalog Storage: First 1 million objects are FREE ($0.00)

3. Serverless Analytics (Amazon Athena Engine):
   - Pricing: $5.00 per 1 TB scanned
   - On Raw CSV: 500 queries * 50 GB avg scan = 25 TB scanned = $125.00 / month
   - On Partitioned Parquet (Column pruning + Snappy compression = 90% scan reduction):
     500 queries * 5 GB avg scan = 2.5 TB scanned = $12.50 / month

4. Total Monthly Serverless Cloud Cost (Optimized Parquet):
   $17.25 (S3) + $6.60 (Glue) + $12.50 (Athena) = $36.35 / MONTH

5. Comparison with Traditional Self-Hosted EC2 Cluster:
   - 3x r5.xlarge worker nodes (32 GB RAM, 4 vCPU) = 3 * $0.252/hr * 730 hrs = $551.88 / month
   - EBS Storage Volumes (3 TB gp3) = $240.00 / month
   - Total Self-Hosted Cluster Cost = ~$791.88 / MONTH
   >>> CONCLUSION: Serverless Cloud Architecture yields a 95.4% COST REDUCTION with ZERO server maintenance!
